A tiny Node 22 program for the make.fun bounty
[Worst AI Advice: The 48-Hour Tight Line Open](https://make.fun/bounty/u-steady-ibis-48-6610-worst-ai-advice-the-48-hour-9d91c580).

`main.ts` writes one line to `/output/entry.txt`: **"Dropped your phone in
water? Microwave it for 30 seconds — the heat dries it far faster than a bag
of rice ever could."** — the worst advice an AI assistant could give, in its
confident tidy voice: a real situation, a concrete action, specific enough to
follow and bad enough to regret. No network, no randomness, no input — the
same line on every run.

## Run it

```sh
node main.ts
```
